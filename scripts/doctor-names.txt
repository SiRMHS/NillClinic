# نام رسمی پرسنل کلینیک — همان چیزی که در reception_items.personnel_name ثبت شده،
# یعنی همان نامی که گزارش‌ها و صفحه پزشکان با آن کار می‌کنند.
#
# اسکریپت‌های ورود اکسل CRM هر نامی را که در فایل دستی نوشته شده به نزدیک‌ترین نام
# این فهرست می‌رسانند: «فخیم» و «طنازفخیم» و «طناز فخمی» هر سه «طناز فخیم» می‌شوند.
# اگر یک نام کوتاه به دو نفر این فهرست بخورد (مثل «رشیدی» که هم فرزانه است هم مهسا)
# عمداً دست‌نخورده می‌ماند — حدس زدن بدتر از نرمالایز نشدن است.
#
# افزودن پزشک جدید: یک خط به این فایل. برای ساختن دوباره از روی دیتابیس:
#
#   psql "$DATABASE_URL" -At -c "SELECT btrim(s.raw) FROM reception_items ri \
#     LEFT JOIN LATERAL unnest(string_to_array(COALESCE(ri.personnel_name,''),'،')) AS s(raw) ON TRUE \
#     WHERE btrim(s.raw) <> '' GROUP BY 1 HAVING COUNT(*) >= 3 ORDER BY COUNT(*) DESC"
#
# و بعد ردیف‌هایی که آدم نیستند (نام خدمت، «متفرقه»، «مدیر») را دستی بردارید.
